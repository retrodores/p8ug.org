Start small, then change something!

A little working program is a great place to start learning Prog8. Try Hello World, then pick an example that does something you want your own machine to do.

Hello World - C64 examples - X16 examples - Shared examples

Hello World

Save this as hello.p8. The textio module gives us text output, and main.start() is where the program begins.

%import textio

main {
    sub start() {
        txt.print("hello world!\n")
    }
}

With the Prog8 compiler and 64tass installed, compile for your machine:

prog8c -target c64 hello.p8
prog8c -target cx16 hello.p8

Run one command for the target you want. Each produces a program for that machine; use separate output folders if you want to keep both. See our releases page and the documentation for setup.

Explore the official examples

The links below take you to Irmen's source files. This is a selection from the full examples directory, with a focus on the C64 and Commander X16. Browse the code, compile an example, and try changing a color, a message, or a movement pattern.

These links follow the development branch. Some examples may need a newer compiler or particular hardware features. Match the source to your compiler version and read the comments before trying it out.

Commodore 64

Browse all C64 examples

  • Balloon sprites - Sets up the eight hardware sprites and uses a raster interrupt. A good place to see sprite data, positioning, and VIC-II registers together.

  • Wizzine - Animates balloon sprites from an interrupt handler. Try changing the movement and see what happens!

  • Raster bars - Moving color bars driven by raster interrupts. A small example for exploring screen timing and color changes.

  • Bank switching - Explores ROM and the RAM underneath it, including changing the BASIC ready prompt. Read the comments about interrupts and ROM access carefully.

  • TehTriz - A complete Tetris-style game with a holding area, next-piece display, wall kicks, increasing speed, and sound effects. A larger example to explore once the small ones make sense.

Commander X16

Browse all X16 examples

  • Cobra Mk III with VERA FX - Draws the spaceship using VERA FX line drawing at 320 by 240 in 256 colors. One to try when you want to explore the X16 graphics hardware.

  • Custom keyboard handler - Installs a key handler and responds to key presses, with Escape to quit. Useful reading for a game or an interactive tool.

  • Conway's Game of Life - Uses cell grids and neighbor counts to run the classic cellular automaton. A fun way to explore arrays, pointers, and updating a world one generation at a time.

  • TehTriz for X16 - The X16 version of the falling-block game, with sound through the VERA PSG. Compare it with the C64 version to see how the same idea fits each machine.

  • Disk speed benchmark - Measures disk transfers with optional verification. This example writes data to disk, so use a disposable test disk or emulator image.

Examples for more than one machine

Not every example needs to be tied to one computer. These examples are marked in their source as supporting multiple targets.

  • Number guessing game - Combines text input, a random secret number, and a limited number of guesses. A nice next step after Hello World.

  • Prime numbers - Uses a sieve to find primes up to 255. Follow the arrays, loops, and subroutines to see how the algorithm comes together.
