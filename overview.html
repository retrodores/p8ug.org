What is Prog8?

Prog8 is a structured, compiled programming language created by Irmen de Jong. It gives us a convenient way to write programs for retro computers while keeping close to the hardware. If you have a C64, C128, or Commander X16 waiting for a new project, this is a fun place to start!

A little structure goes a long way

Prog8 lets you organize a program into modules and subroutines, use loops and named variables, and work with strings and arrays. The compiler turns that source into native machine code for your target computer. You write the program on a modern computer, compile it, and try it out in an emulator or on the real thing.

You can also read and write memory directly, call ROM routines, and mix in assembly when you need control over a particular piece of code. There is still plenty of room to learn what makes these machines tick!

What can you make?

Games, little utilities, graphics experiments, or that project you always wanted to finish back in the day. The included examples are a good way to see what is possible, and the Show & Tell page has more software to explore.

The Commander X16, Commodore 64, and Commodore 128 are supported targets. Other machines have varying levels of support, including experimental Amiga targets. Check the documentation for the details for your machine and compiler version.

Give it a try

Start with an official release and follow the setup instructions in the documentation. For the 6502 targets, the compiler uses Java and the 64tass assembler. An emulator is handy for trying things out as you go.

Pick a small example, get it running, and change something. Before long you will have a project of your own to share with the crew.

Where does P8UG fit in?

We are a loosely affiliated group of retro computing enthusiasts who enjoy using Prog8 and helping each other along. You do not have to be an expert to join. If you like Prog8, use it, or positively support the community, then you are a member!

Join the #prog8-dev channel on Discord to share a project, ask a question, or see what others are working on. You can also visit the Prog8 forum.

Irmen puts a lot of work into Prog8. If you enjoy using it, send him a thank you donation!
